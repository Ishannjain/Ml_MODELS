# AI & Machine Learning Projects Portfolio

This repository contains a collection of end-to-end Artificial Intelligence and Machine Learning projects covering classification, regression, recommendation systems, NLP, computer vision, forecasting, and deployment with web applications.

Each project demonstrates a practical problem-solving approach using real-world datasets and modern machine learning workflows.

---

## 1. AI Resume Screening System

### Problem Statement
Automating the hiring process is challenging because recruiters must manually review many resumes and identify the most suitable candidates. The goal is to reduce manual effort and improve recruitment efficiency.

### Solution
A machine learning-based resume screening system is built to process resumes, extract useful information, and classify candidates based on job relevance. The project uses NLP and classification techniques to support faster candidate shortlisting.

### Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- NLP preprocessing tools
- Streamlit
- Joblib

## Explanation of the Tech Stack

Each technology used in this portfolio serves a specific purpose in the machine learning workflow:

- Python: The main programming language used to build all projects because of its simplicity and strong support for data science and AI.
- Pandas: Used for cleaning, transforming, and analyzing structured data in tables and DataFrames.
- NumPy: Provides fast numerical operations and is widely used for mathematical calculations and array manipulation.
- Matplotlib and Seaborn: Used for visualizing datasets, model results, trends, and patterns through charts and plots.
- Scikit-learn: A powerful machine learning library used for classification, regression, clustering, preprocessing, and evaluation metrics.
- NLTK: Helps with natural language processing tasks such as tokenization, stopword removal, and text cleaning.
- TensorFlow and Keras: Used for building and training deep learning models, especially for image-based tasks.
- OpenCV and Pillow: Used for image reading, preprocessing, and manipulation in computer vision projects.
- Streamlit: Used to create interactive web applications so users can upload data or images and get predictions instantly.
- Joblib: Used to save trained models and other machine learning artifacts for reuse.
- Statsmodels, Prophet, and XGBoost: Used for time-series forecasting, trend analysis, and advanced predictive modeling.
