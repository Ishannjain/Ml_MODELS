# AI Interview Assistant

## Overview
The AI Interview Assistant is a web application designed to help users prepare for interviews by providing personalized AI-generated questions, feedback, and performance evaluations. The application allows users to upload their resumes, configure interview settings, and receive tailored feedback based on their responses.

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd ai-interview-assistant
   ```
3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage
1. Start the Streamlit application:
   ```
   streamlit run app/main.py
   ```
2. Open your web browser and go to `http://localhost:8501` to access the application.

## Features
- **Resume Analysis**: Upload your resume to identify key skills and experiences.
- **AI Interview**: Practice with personalized interview questions generated by AI.
- **Performance Report**: Receive an evaluation of your interview performance.
- **AI Feedback**: Get tailored feedback on your strengths and areas for improvement.
