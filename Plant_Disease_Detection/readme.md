# 🌿 Plant Disease Detection using Deep Learning

## Overview

Plant Disease Detection is a Deep Learning-based Computer Vision project that classifies plant leaf images into healthy or diseased categories. The system uses Transfer Learning with MobileNetV2 to achieve high accuracy while maintaining a lightweight model suitable for deployment.

The trained model is deployed using Streamlit, allowing users to upload a leaf image and instantly receive the predicted disease.

---

## Objectives

- Detect plant diseases from leaf images.
- Classify healthy and diseased leaves.
- Build a high-accuracy CNN model.
- Deploy the model using Streamlit.
- Create a professional portfolio project.

---

## Dataset

- Dataset: PlantVillage
- Images: ~54,000+
- Classes: 38
- Image Type: RGB Images
