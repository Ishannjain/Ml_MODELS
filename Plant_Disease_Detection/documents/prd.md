# Product Requirements Document

## Project Name

Plant Disease Detection

---

## Problem Statement

Farmers often struggle to identify plant diseases accurately. Manual diagnosis requires agricultural expertise and is time-consuming.

This project provides an AI-powered solution capable of identifying plant diseases from leaf images.

---

## Goals

- Build an accurate disease classification model.
- Reduce disease identification time.
- Support farmers with AI.
- Deploy a user-friendly web application.

---

## Functional Requirements

### User

- Upload image.
- Predict disease.
- Display confidence.
- Display disease category.

### Admin

- Train model.
- Save model.
- Update model.

---

## Non Functional Requirements

- High Accuracy
- Fast Prediction
- Responsive UI
- Easy Deployment
- Lightweight Model
