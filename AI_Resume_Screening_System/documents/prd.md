# Product Requirement Document

## Project Name

AI Resume Screening System

---

## Objective

Develop a Machine Learning application that automatically classifies resumes into job categories using NLP.

---

## Target Users

- HR Professionals
- Recruiters
- Students
- Companies
- Hiring Platforms

---

## Functional Requirements

- Upload Resume
- Extract Resume Text
- Clean Resume
- Predict Category
- Display Confidence
- Detect Skills
- Show Resume Statistics

---

## Non Functional Requirements

- Fast Prediction
- User Friendly UI
- High Accuracy
- Lightweight Deployment

---

## Success Criteria

Accuracy above 95%

Prediction time below 2 seconds

Responsive UI
