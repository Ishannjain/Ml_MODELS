# AI Resume Screening System

## Overview

The AI Resume Screening System is an NLP-based Machine Learning application that classifies resumes into different job categories. It uses TF-IDF vectorization and a trained machine learning model to predict the most suitable category for a given resume.

---

## Features

- Resume Classification
- PDF Resume Upload
- TXT Resume Upload
- Resume Preview
- Skill Extraction
- Top 5 Predictions
- Prediction Confidence
- Resume Statistics
- Streamlit Web Interface
