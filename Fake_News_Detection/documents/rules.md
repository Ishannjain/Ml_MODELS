# Development Rules

## Coding Rules

- Follow PEP 8
- Modular code
- Meaningful variable names
- Separate notebook phases

---

## Dataset Rules

- Keep original dataset unchanged
- Save processed dataset separately
- Remove duplicates
- Handle missing values

---

## NLP Rules

- Lowercase all text
- Remove punctuation
- Remove stopwords
- Apply stemming
- Use TF-IDF

---

## Machine Learning Rules

- Train multiple models
- Compare evaluation metrics
- Save best model

---

## Visualization Rules

- Save charts
- Proper titles
- Proper labels

---

## Deployment Rules

- Never retrain model
- Load saved model
- Validate input

---

## Documentation Rules

Every project must contain

README.md

Architecture.md

PRD.md

Rules.md

LICENSE

.gitignore
